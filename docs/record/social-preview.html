fghj

open source · macOS · Linux

Real HTTPS hostnames for multi-repo local dev, the same inside Docker and out.

Bring up only the services your user flow needs. No compose file to maintain.

from your laptop
curl localhost:9000 9001 9002
$ curl https://api.shop.fghj.internal/health
from inside any container
curl host.docker.internal:9000 9001 9002
$ curl https://api.shop.fghj.internal/health
